# Always

- lint (rust, typescript)
- format (rust, typescript)
- test (rust, typescript)
- Adhere to SOLID design
- Adhere to clean code
- Cyclomatic complexity should always be considered an if over 3 think if it could be handled better.
- Use adapter pattern around hard to test 3rd parties
- If a file exceeds 100 lines, break it into smaller files inside a module
- If a function exceeds 30 lines, break it into smaller functions
- Test behavior not implementation

# Never

- Break existing tests without explicit approval
- use emojis
